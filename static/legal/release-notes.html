Stratus Browser 0.1.0-alpha

Built on Gecko 153 (Firefox ESR) · Stratus overlay layer 0.1

Welcome to the first milestone release of Stratus. This build is the developer-preview milestone and establishes the foundation for a user-ready browser.

What's new

  • Transparent traffic overview: a network monitor panel reports which sites, tabs, and extensions are making requests, split between normal and private mode.
  • Complete settings, new-tab, welcome, and notes pages as native Stratus pages.
  • Workspaces, split-view, panel sidebar, mouse gestures, and command palette integrated into the Stratus tool set.
  • Stratus-branded legal pages: this page and the privacy policy now ship inside the browser — no third-party placeholder content.

Known limitations

  • Response-byte accounting for web content is pending (content-side instrumentation); the traffic overview reports exact request counts today.
  • Runtime-level rebranding (window title, about dialog branding, installer) lands in a later milestone.
  • Private-mode VPN separation and trusted-site action allowlists are in active development.
